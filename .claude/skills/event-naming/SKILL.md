# 이벤트 이름 짓기

## 언제 쓰나

GA4로 보낼 이벤트 이름을 지어 달라고 하거나, 이벤트 이름을 검토해 달라고 할 때 쓴다.

## 무엇을 받나

사용자가 한 행동을 설명한 문장.

예: "장바구니에 담긴 상품을 지웠다", "주문서 화면에서 결제하기를 눌러 결제를 마쳤다"

## 어떤 순서로 하나

1. 행동 문장에서 사용자가 한 일(동사)을 찾는다.
2. 그 동사를 영어로 바꿔 맨 앞에 두고 이름을 짓는다.
3. 아래 규칙을 모두 지키는지 하나씩 확인하고, 어긋나면 고친다.

## 규칙

- 영문 소문자로 시작한다.
- 영문 소문자, 숫자, 밑줄만 쓴다.
- 낱말 사이는 밑줄로 잇는다.
- 40자를 넘기지 않는다.
- `ga_` 나 `google_` 나 `firebase_` 로 시작하지 않는다.
- 한글, 띄어쓰기, 대문자를 쓰지 않는다.
- 누른 단추 이름이 아니라 그 단추로 한 일로 짓는다.
- 이름만 보고 무슨 행동인지 읽혀야 한다.

## 무엇을 내놓나

세 칸짜리 표 한 줄.

| 이름 | 언제 | 왜 재나 |
| --- | --- | --- |
| remove_cart_item | 장바구니 화면에서 상품의 삭제 단추를 누른 순간 | 어떤 상품이 담겼다가 빠지는지 보고 값을 내릴지 묶음을 바꿀지 정한다 |

- 언제 칸에는 사용자가 어느 화면에서 무엇을 누른 순간인지 적는다.
- 왜 재나 칸에는 이 숫자로 무엇을 결정할 수 있는지 한 문장으로 적는다. "분석을 위해" 같은 말은 쓰지 않는다.
